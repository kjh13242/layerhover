Layerhover — Figma 데스크톱 앱 도우미 (비공식)
=======================================================

Figma 데스크톱 앱에서 패널을 접어 두고(Minimize UI), 마우스를 화면 왼쪽 끝에 대면
패널이 펼쳐졌다가 벗어나면 다시 접히게 해 줍니다.
왼쪽 아래 페이지 버튼과 단축키로 패널을 열지 않고도 페이지를 찾아 옮길 수 있고,
Figma 작업 시간을 이 Mac에만 기록해 주간 요약으로 보여 줍니다.
Figma의 공식 제품이 아니며 Figma와 관련이 없습니다.

설치 (처음 한 번)
-----------------
1. Layerhover.app을 "응용 프로그램" 폴더로 옮깁니다.

2. Layerhover를 엽니다. 안내 창이 뜹니다.
   "확인되지 않은 개발자" 경고가 뜨면 창을 닫고,
   시스템 설정 > 개인정보 보호 및 보안 > 아래쪽의 "그래도 열기"를 누릅니다.
   (터미널이 편하면 아래 한 줄로도 됩니다.)

     xattr -dr com.apple.quarantine /Applications/Layerhover.app

3. 안내 창의 "손쉬운 사용 설정 열기"를 누르고 Layerhover를 켭니다.
   (시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용)
   Figma 안의 접기/펼치기 버튼을 대신 누르는 데 필요한 권한입니다.
   권한을 켜면 Layerhover가 1~2초 뒤 스스로 다시 켜집니다. 그 뒤부터 동작합니다.

4. 안내 창이나 메뉴 막대 아이콘에서 "로그인할 때 자동 실행"을 켜 두면
   다시 실행할 필요가 없습니다.

사용법
------
1. Figma 파일은 최소화 모드(Shift+Cmd+\)로 시작합니다. Layerhover가 처음 보는 파일을
   한 번 이 모드로 맞춰 줍니다. 오브젝트를 선택하면 오른쪽 속성 패널은 Figma가 보여 줍니다.
2. 마우스를 화면 왼쪽 끝에 대면 패널이 펼쳐집니다.
3. 마우스가 패널을 벗어나면 다시 접힙니다.

- 직접 펼친 패널은 자동으로 접지 않습니다.
- 분할 화면에서는 마우스가 있는 쪽만 반응합니다. 오른쪽 화면은 가운데 경계가 왼쪽 끝입니다.
- 오른쪽 끝은 기본으로 반응하지 않습니다. 오브젝트를 선택하면 Figma가 오른쪽 속성 패널을
  띄워 주기 때문입니다. 필요하면 메뉴 막대 아이콘에서 "오른쪽 끝에서도 펼치기"를 켜세요.
- 패널에서 메뉴가 열려 있거나 레이어 이름을 편집하는 동안에는 접지 않습니다.
- UI를 완전히 숨기는 모드(Cmd+\)도 쓸 수 있습니다. 최소화 모드는 처음 연 파일에만 적용됩니다.
- 메뉴 막대 아이콘을 누르면 패널이 뜹니다. 맨 위 스위치로 일시 정지하고, "설정"을 펼쳐 오른쪽 끝 반응과
  "새 파일을 최소화 모드로 맞추기"를 바꿀 수 있습니다.
- 문제가 생기면 메뉴 막대 아이콘 > 패널 맨 아래 "문제 기록"으로 기록 파일을 찾아 보내 주세요.
  기록 파일에는 Figma 파일 이름과 페이지 이름이 들어 있습니다. 다른 사람에게 보내기 전에 확인하세요.
  기록은 이 Mac에만 있고 1MB를 넘으면 지난 내용을 정리합니다.

페이지 바로가기
---------------
Figma 화면 왼쪽 아래(아래쪽 도구 막대 옆)에 지금 페이지 이름이 담긴 버튼이 뜹니다.

- 버튼을 누르거나 Ctrl+Option+P: 페이지 이동 창이 열립니다. 이름을 몇 글자 치고 Enter.
  위·아래 화살표로 고르고, esc로 닫습니다. 최근에 간 페이지가 맨 위에 나옵니다.
- 버튼 오른쪽의 ‹ › 로 이전·다음 페이지로 갑니다 (버튼이 좁아 이름이 잘릴 때는 숨깁니다).
  단축키: Ctrl+Option+← / Ctrl+Option+→
- 단축키는 Figma가 앞에 있을 때만 동작합니다. 다른 앱의 같은 키는 막지 않습니다.
- 버튼 폭은 도구 막대까지 남은 공간에 맞춰 줄어듭니다. 좁으면 아이콘 하나만,
  그보다 좁으면 숨었다가 공간이 생기면 다시 나타납니다.
- 메뉴 막대 아이콘 > 설정에서 버튼과 단축키를 각각 끌 수 있습니다.

알아 둘 점
- 페이지를 옮길 때 왼쪽 패널이 0.2~0.4초 펼쳐졌다 접힙니다. Figma는 패널이 접혀 있으면
  페이지 목록을 만들지 않아서, 잠깐 펼쳐 누르는 방법밖에 없습니다.
- Layerhover는 페이지 목록을 읽으려고 패널을 저절로 펼치지 않습니다. 처음 보는 파일은 버튼에
  "페이지 선택"이라고 나오고, 버튼이나 단축키를 처음 쓸 때 한 번 읽습니다(패널이 잠깐 펼쳐짐).
  그 뒤로는 파일별로 기억해 두어 바로 이름이 나옵니다.
- 버튼이 있는 화면 아래쪽 띠(약 76pt)에서는 왼쪽 끝에 닿아도 패널이 펼쳐지지 않습니다.
  버튼을 누르러 가다 패널이 열리는 것을 막기 위해서입니다.
- 이전·다음으로 갈 페이지가 없으면 ‹ › 가 흐리게 보입니다.
- 다른 방법으로 페이지를 옮겨도 Figma 주소를 보고 버튼 이름을 맞춥니다. 처음 가 보는
  페이지는 이름을 아직 몰라서, 패널이 한 번 펼쳐진 뒤부터 맞게 나옵니다.
- UI를 완전히 숨긴(Cmd+\) 상태에서는 페이지를 옮길 수 없습니다.
- 패널이 잠깐 펼쳐지는 모습이 거슬리면 메뉴 막대 아이콘 > 설정 > "이동할 때 패널 가리기"를 켜세요.
  옮기기 직전 화면을 찍어 덮어 두었다가 걷어 내서, 패널이 보이지 않고 새 페이지로 넘어갑니다.
  화면 기록 권한이 필요하고(시스템 설정 > 개인정보 보호 및 보안 > 화면 및 시스템 오디오 녹음),
  권한을 켠 뒤 Layerhover를 다시 켜야 합니다. macOS 14 이상에서 동작합니다. 찍은 화면은 저장하지 않습니다.

작업 기록
---------
메뉴 막대 아이콘 > "이번 주 작업"에서 이번 주 Figma 작업을 볼 수 있습니다.
- 작업 시간: Figma가 앞에 있고 키보드·마우스를 쓰고 있던 시간 (2분 넘게 손을 놓으면 빼고 셉니다)
- 집중 시간: 다른 앱에 30초 넘게 가지 않고 10분 넘게 이어진 작업 구간
- 파일·페이지별 시간, 페이지 이동 횟수(Layerhover로 / 직접), 다른 앱으로 넘어간 횟수
- CSV로 내보낼 수 있고, 기록을 모두 지울 수도 있습니다.
- 기록은 이 Mac(~/Library/Application Support/Layerhover/Activity)에만 저장되고 밖으로 보내지 않습니다.
  끄려면 메뉴 막대 아이콘 > 설정 > "작업 기록 남기기"를 끄세요.

Claude 작업 상태
----------------
Claude가 Figma 파일을 고치는 동안 페이지 버튼 아이콘이 주황색 ✦ 로 바뀝니다.
- Figma에 AI 에이전트가 연결되면 따로 설정 없이 표시됩니다.
- Claude Code를 쓴다면 메뉴 막대 아이콘 > 설정 > "Claude Code와 연결하기…"를 눌러 복사된 설정을
  ~/.claude/settings.json 의 "hooks"에 붙여 넣으세요. Claude가 Figma 도구를 쓰는 동안
  ✦ 가 숨 쉬듯 깜빡이고, 버튼에 마우스를 올리면 쓰는 도구 이름이 보입니다.

펼치고 접히는 속도 조절
----------------------
메뉴 막대 아이콘 > 설정 > 펼치는 속도 / 접히는 속도에서 고릅니다. 바로 적용됩니다.

펼치는 속도 (화면 왼쪽 끝에 닿은 뒤)
  바로        닿자마자 펼침
  빠르게      0.06초 머물면 펼침 (기본)
  천천히      0.3초 머물면 펼침. 화면 끝을 자주 스칠 때 실수로 펼쳐지는 걸 막음

접히는 속도 (패널을 벗어난 뒤)
  바로        패널 경계를 벗어나는 즉시 접힘
  빠르게      0.12초 뒤, 경계에서 12pt 벗어나면 접힘 (기본)
  여유 있게    0.4초 뒤, 경계에서 30pt 벗어나면 접힘

알아 둘 점
----------
- 패널은 캔버스 위에 겹쳐서 펼쳐지고, 캔버스는 움직이지 않습니다.
- UI를 숨긴(Cmd+\) 화면은 Layerhover가 Cmd+\ 키를 대신 눌러서 꺼내고 넣습니다.
  일본어(JIS) 키보드처럼 \ 키 위치가 다른 키보드에서는 이 모드가 동작하지 않을 수 있습니다.
- Figma가 화면 구조를 크게 바꾸면 동작하지 않을 수 있습니다. 그때는 새 버전이 필요합니다.
- 새 버전으로 교체하면 손쉬운 사용 권한을 다시 켜야 할 수 있습니다
  (목록에서 Layerhover를 지우고 다시 추가).
- macOS 13 이상, Figma 데스크톱 앱 전용입니다. Figma의 공식 제품이 아닙니다.

메뉴 막대 아이콘
----------------
메뉴 막대 아이콘은 14가지 가운데 고를 수 있고, 저마다 다르게 움직입니다.
  반가사유상(고쳐 앉기), 파도(너울이 지나감), 서핑(파도를 탐), 낚시(입질 두 번 뒤 낚아챔), 크리스마스 나무(불빛),
  목련(바람에 흔들림), 연꽃(오므렸다 핌), 석탑(눈이 내림), 향(연기가 한 줄기 또는 두 줄기), 북두칠성(별이 차례로 빛남),
  고양이와 나비, 나뭇잎(가지에서 흔들림), 옆에서 나오는 패널, 날씨(지금 위치의 날씨)
- 메뉴 막대 아이콘을 눌러 패널의 "메뉴 막대 아이콘"에서 고릅니다. 마우스를 올리면 그 아이콘이 움직여 보입니다.
- "아이콘 움직임"을 끄면 멈춘 그림만 보입니다.
- 일시 정지했거나, macOS의 "동작 줄이기" 또는 "저전력 모드"가 켜져 있으면 움직이지 않습니다.
- 아이콘이 흐리게 멈춰 있으면 일시 정지했거나 손쉬운 사용 권한이 없는 상태입니다. 아이콘을 누르면 패널이 알려 줍니다.
- 움직이는 동안에도 CPU를 거의 쓰지 않습니다(화면 합성기가 그림의 칸만 옮깁니다).

날씨 아이콘
-----------
"날씨"를 고르면 지금 위치의 날씨가 메뉴 막대에 움직이는 그림으로 나옵니다
(맑음, 맑은 밤, 구름 조금, 흐림, 비, 눈, 뇌우, 안개).
- 처음 고를 때 위치 권한을 묻습니다. 날씨 아이콘을 고른 동안만 위치를 쓰고, 다른 아이콘으로 바꾸면 쓰지 않습니다.
  (권한 자체를 끄려면 시스템 설정 > 개인정보 보호 및 보안 > 위치 서비스)
- "날씨 표시"에서 아이콘만 / 온도와 함께를 고릅니다. 온도를 받는 동안은 흐린 "–°"가 보입니다.
- 30분마다 새로 받습니다. 대략적인 위치(소수 둘째 자리, 약 1km)를 Open-Meteo로 보내고,
  거기에 닿지 않는 네트워크에서는 wttr.in 을 씁니다. 위치와 날씨는 저장하지 않습니다.

EdgePeek에서 옮겨 오기
-----------------------
Layerhover의 예전 이름은 EdgePeek입니다. Layerhover를 처음 켜면 EdgePeek의 설정, 파일별 페이지 목록,
작업 기록을 한 번 복사해 옵니다(EdgePeek 쪽 데이터는 지우지 않습니다).
EdgePeek.app은 종료하고 지워 주세요. 둘이 함께 켜져 있으면 패널을 서로 펼치고 접습니다.
손쉬운 사용 권한과 "로그인할 때 자동 실행"은 Layerhover에서 다시 켜야 합니다.

삭제
----
메뉴 막대 아이콘 > 패널 맨 아래 "종료"를 누른 뒤, 응용 프로그램 폴더에서 Layerhover.app을 지웁니다.
남는 데이터까지 지우려면 아래도 지웁니다.

  ~/Library/Application Support/Layerhover          작업 기록, Claude 상태 파일
  ~/Library/Logs/Layerhover.log, Layerhover.old.log   문제 기록
  ~/Library/Preferences/app.layerhover.Layerhover.plist   설정, 파일별 페이지 목록

Homebrew로 설치했다면 아래 한 줄로 앱과 데이터를 함께 지웁니다.

  brew uninstall --zap --cask layerhover
