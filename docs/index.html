패널 꺼내기

닿으면 나오고,
벗어나면 접혀요.

  • 왼쪽 끝에 대면 레이어 패널패널을 접어 둔 채 일하다가, 화면 왼쪽 끝에 마우스를 대면 레이어 패널이 펼쳐져요.
  • 벗어나면 저절로 접혀요패널 밖으로 마우스를 옮기면 다시 접혀서 캔버스가 넓게 남아요.
  • 오른쪽 끝은 속성 패널설정에서 켜면 오른쪽 끝에서 속성 패널도 같은 방식으로 꺼내요.

위 데모의 Figma 창 왼쪽 끝에 직접 대 보세요.

  • 다른 앱에서 바로메뉴 막대의 ‘Figma 페이지로’를 누르면 Figma를 앞으로 가져와 원하는 페이지를 열어요.
