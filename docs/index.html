07 설치

설치는 한 줄,
업데이트는 알아서.

$ brew install --cask kjh13242/layerhover/layerhover

또는 GitHub Releases에서 Layerhover.zip 받기 → 응용 프로그램 폴더로 옮기기.

  1. 열기. 서명되지 않은 앱이라 처음엔 "확인되지 않은 개발자" 경고가 뜰 수 있어요. 시스템 설정 > 개인정보 보호 및 보안에서 그래도 열기, 또는 xattr -dr com.apple.quarantine /Applications/Layerhover.app
  2. 손쉬운 사용 켜기. 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용에서 Layerhover를 켜요.
  3. Figma에서 패널 접기.
Layerhover는 Figma의 공식 제품이 아니며 Figma와 관련이 없어요.
